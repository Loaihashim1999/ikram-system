## 3. بنية كائن الصلاحيات الدقيقة (`users.permissions` JSON Structure)

يتم تخزين التخصيصات الدقيقة لكل مستخدم بصيغة JSON قابلة للتوسع:

```json
{
  "beneficiaries": {
    "view": true,
    "create": true,
    "edit": true,
    "delete": false,
    "import": true,
    "export": true,
    "notifications": true
  },
  "warehouse": {
    "view": true,
    "create": false,
    "edit": false,
    "delete": false,
    "import": false,
    "export": true,
    "notifications": true
  },
  "delivery": {
    "view": true,
    "create": false,
    "edit": false,
    "delete": false,
    "issue_document": true,
    "notifications": false
  }
}
```
- إذا كان `permissions[$module]['view']` يساوي `false`، يتم رفض الطلب فوراً برمز `403 Forbidden` حتى لو كان دور المستخدم يسمح بذلك في الواجهة الأمامية.
- إذا لم يُعرّف الحقل الخاص بالعملية، يتم الرجوع إلى الدور الافتراضي.
